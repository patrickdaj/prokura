# Progress blog

A running, visual build log — one page per milestone, written for an outsider:
what we built, how it works, the decisions and gotchas, how it was verified, and
a "Run it yourself" section. Each page is a self-contained, theme-aware HTML file
in Prokura's own visual language.

These are the **source** for the hosted pages. The published, shareable versions
live as Claude artifacts:

Open any file directly in a browser, or view the hosted version. The pages
cross-link (the `PROKURA` wordmark returns to the M0 hub).

## Conventions

- One page per milestone; M0 doubles as the series front door and roadmap.
- Each new milestone slots into the M0 roadmap and gets its own page here.
- A full end-to-end **walkthrough** is deliberately deferred to a capstone
  (M6 / demo) rather than duplicated across every page.
- To update a hosted page, edit the source here and re-publish it to the same
  artifact URL.
