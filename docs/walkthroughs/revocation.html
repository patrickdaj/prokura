Surface · the kill switch

How fast can you make an agent stop?

M8 let you revoke a delegation; the console said "effect on the agent's next request." M9 turns that into a measured number of milliseconds. A per-grant revoke deletes the consent tuple, writes a broker deny-list entry, and emits a CAEP signal — instant and scoped. The one window it can't close — a provider token already handed out — it bounds and reports. Every screen below is captured live.

01

One click, a measured stop

Revoking an agent from the console (or the M7 consent surface) runs the broker's kill: tuple delete + deny-list entry + CAEP signal. The console reports the measured time to deny new authority and the honest in-flight residual — no "next hand-out" hand-waving.

localhost:8160 — revoke, with a number
What it proves: revocation is instant and legible — a millisecond number, not a promise about the future.
02

The deny-list — a propagation-free "stop now"

Every hand-out checks a broker deny-list before the provider is contacted, independent of any OpenFGA read consistency. So a revoked agent is refused even holding a brand-new user token — a fresh token is no way around revocation.

the hand-out chain, after revoke
$ revoke agent-app / acme     → tuple gone + deny-list entry + CAEP signal   # ~12 ms
$ tokens/acme  (fresh token)  → 403 revoked   # deny-list denies before contacting the provider
# re-acquiring the revoked grant is impossible without re-consent — no stale-token trick
What it proves: the stop does not depend on token expiry or FGA propagation — it is enforced on every request.
03

Honest about the one thing we can't kill

A provider token already in the agent's hand keeps working at the provider until it expires — the mock acme has no revocation endpoint, and pretending otherwise would be a lie. So M9 bounds the hand-out TTL to 120 s and reports the residual instead of hiding it.

the in-flight residual, disclosed
tokens/acme  → provider access token, expires_in=120   # bounded, not 900
acme userinfo(token) → 200
$ revoke everything
acme userinfo(same token) → 200   # still valid until ≤120 s — reported, not falsely "revoked"
// real providers (GitHub/Google) support token revocation → this residual closes in M12
What it proves: the answer is honest — new authority stops in milliseconds; the small remaining window is named, per ADR-0003.
04

The agent-wide kill — it can't re-acquire

To stop an agent entirely, the agent-wide kill also revokes the agent client's Keycloak sessions and offline/refresh tokens for that user — a targeted consent delete, needing only manage-users. A re-mint then fails; the human's own sessions are untouched. The spike proved the exact API and minimal role before any code.

Keycloak revocation, scoped to the agent
DELETE realms/prokura/users/{alice}/consents/agent-app   → 204   # manage-users
refresh_token(agent-app)  → 400 invalid_grant   # can't re-acquire ANY authority
alice interactive sessions: before=3  after=3   // the human is not logged out
What it proves: the offline-token persistence path is closed for a full kill, scoped to the agent client — never the human.
05

The answer, on the dashboard

Every revoke records a prokura.revocation.stop_ms metric, joinable to its trace and audit line. "How fast can you make an agent stop?" now has a live answer.

localhost:3001 — time to stop
What it proves: the security team's first question is answered with a number on the operator dashboard, not a shrug.

What this surface guarantees

  • ✓A per-grant revoke denies new authority in low tens of milliseconds — tuple delete + a deny-list checked on every hand-out.
  • ✓Re-acquiring the revoked grant is impossible with a fresh token — the deny-list denies before the provider is contacted.
  • ✓The in-flight residual (a token already issued) is bounded (≤120 s) and reported, never falsely claimed revoked.
  • ✓The agent-wide kill revokes the agent's Keycloak sessions/offline tokens so it can't re-acquire — scoped to the agent, never the human.
  • ✓Revocation is emitted as a CAEP Security Event Token and measured on the dashboard.

The kill fan-out, the propagation-free deny-list, the agent-wide Keycloak kill, and the honest in-flight residual are ADR-0024.
